# Awesome conventions and submission eligibility

Checked against the [Awesome manifesto](https://github.com/sindresorhus/awesome/blob/main/awesome.md), [list instructions](https://github.com/sindresorhus/awesome/blob/main/create-list.md), and [submission checklist](https://github.com/sindresorhus/awesome/blob/main/pull_request_template.md) on 2026-10-28.

The repository follows the practical list conventions: a focused scope, a conventional title and badge, contents, topic sections, concise descriptions explaining usefulness, related lists, contribution instructions, CC0 bibliography licensing, lowercase repository name, `main` branch, and Awesome topics. The README is curated separately from the automatically generated catalogue.

This is **not a claim of upstream eligibility**. The current checklist requires a list that is not AI-generated, a non-generated Markdown file, at least 30 days of public history, and other contribution/review conditions. This initial list was prepared with AI assistance and does not meet the non-AI-generated requirement. Reformatting generated text or passing a linter does not change that. A maintainer would need to do genuine independent editorial work and reassess upstream policy before any submission. No upstream pull request has been created.
